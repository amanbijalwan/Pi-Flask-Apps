# Flask Apps for Raspberry Pi

This repository contains **Flask-based applications** designed to run on a Raspberry Pi.  
The focus is on **robotics simulations** and **basic simulation dashboards**, making it easy to prototype, test, and visualize robotics-related workflows directly on lightweight hardware.

---

## 🎯 Purpose
- Provide a collection of Flask apps tailored for Raspberry Pi.
- Explore robotics simulations, control panels, and monitoring dashboards.
- Serve as a foundation for experimenting with robotics + web integration.

---

## 📂 Project Structure
Each app lives in its own folder:
- `dashboard/` → System monitoring and stats (CPU, memory, sensors).
- `quote_generator/` → Example app with JSON-driven content and GUI.
- `robotics_sim/` → Flask endpoints for robotics simulation/control.
